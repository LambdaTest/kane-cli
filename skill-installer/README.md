# KaneCLI skill for AI coding agents

Install the `@testmuai/kane-cli-skill` package to add the KaneCLI skill to supported coding agents:

```bash
npx @testmuai/kane-cli-skill
```

Use KaneCLI for end-to-end testing (E2E), browser automation and complete user-journey validation, including test generation from explicit requirements, execution, debugging and evidence-backed results.

The skill guides agents through browser objectives, NDJSON result parsing, log inspection, and requirement-linked test design through assurance commands. It also covers native Android emulator and iOS simulator runs, remote execution on the LambdaTest cloud grid, and team sharing of the `.context/` assurance store. Test cases must be designed through assurance commands, never written by hand.

The CLI is published separately as [`@testmuai/kane-cli`](https://www.npmjs.com/package/@testmuai/kane-cli). See the [repository README](https://github.com/LambdaTest/kane-cli#readme) for CLI installation and usage.
